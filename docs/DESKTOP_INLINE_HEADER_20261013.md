# 电脑端单行页头

## 范围

用户明确要求整条状态信息移到标题同一行。修改共用 `ErpPageHeader`，不改业务逻辑、查询、权限或数据。本次按用户要求合入本地 `main`，不推送、不部署。工作区为 `/private/tmp/gpu-erp-voice-release-20261011`，基线 `3d5040e`，开始时干净。

- ≥1024px：标题｜日期与状态｜主操作/导出/更多。同排居中，日期与状态入口使用已有 36px 档位。
- 状态按实际剩余宽度及真实文字尺寸测量，不按整屏宽度猜数量。放不下的完整项收入原 Popover；数字不缩写，原动作不改变。小槽位以带无障碍名称的更多图标显示。
- 隐藏测量内容不含业务动作，并设置 inert/aria-hidden 和裁剪，不制造第二组可点击入口。
- 长标题保留完整 DOM 文本及 Tooltip。侧栏/字体/窗口变化通过 ResizeObserver 重新测量；布局变动关闭旧菜单，避免触发器重现时意外弹出。
- 手机和平板保留旧投影；独立手机首页、库存搜索/扫码、底部导航不变。
- 财务单行模式清除旧页头底部留白，不改变财务数据或卡片。
