# 全局 UI 收敛

范围：用户提出的七项外观优化；沿用现有 Typography、颜色、控件、页面和财务/库存控制器。未合并、推送或上线。

## 实现

1. 桌面表格正文保持 14px，辅助字段/表头统一为 13px；补充共享表格字号 token，辅助文字和图表坐标颜色提高对比度。手机输入框仍为 16px，触控规则不变。
2. `ErpListPage` 区块计数使用 `DashboardSection.count` 的灰字行内计数，不再使用带状态圆点的蓝色徽章。手机仍只在标题处给出列表计数。
3. `ErpMetricCard` 隐藏没有指标值或无权限的卡片，真实零值、负值保留。指标网格按可用节点计数，不留下空格；只删除精确匹配的重复筛选说明，风险/时间/计算含义不删。财务手机端 `MetricsRegion` 默认展开两项，更多通过原指标区展开；桌面不会被手机数量限制截断。
4. 财务明细、销售利润、往来账款、行情和组装沿用底部搜索。只有存在已授权的主操作时才增加按钮；只读报表不凭空增加新建入口。行情新建复用原弹窗，组装入口展开原表单。组装编辑时隐藏列表搜索，关闭折叠表单后恢复导航，避免隐藏表单误触发任务模式。
5. 桌面共享页头保留主操作和导出，其余动作放入共享 Popover；日期/状态放下一行。所有原动作、权限、禁用状态和确认保留。Popover 保持子组件挂载，避免内部窗口因菜单关闭而丢失状态。
6. 共享表格支持 `emptyAction`，列表模板接入已有授权的新建动作；加载/失败时不误显示空数据新建。两类趋势图以有效数值及不同日期判断：少于两个有效日期显示数据不足，零值有效，隐藏系列不参与判断。
7. 首页手机时段复用 `ErpSegmentedControl`；库存视图本来已使用同一控件。页面导航保持下划线页签，列表筛选保持蓝底快捷按钮，不重做业务导航。

## 验证

- 本地 lint、类型及构建通过。完整测试 1828 项：1791 通过、37 跳过、0 失败。
- 41 项针对性共享组件测试通过；额外导航/搜索守护测试通过。
- 九页（销售、收入、流水、提成、利润、行情、组装、库存、首页）在 320/390px 共 18 组：根节点无横向溢出。四类财务页初始只展开两项有效指标。
- 五页（销售、收入、流水、利润、行情）在 1024/1440px 共 10 组：根节点无横向溢出，桌面有效指标保留。
- 浏览器计算字号：表格正文 14px，辅助文字 13px，辅助文字颜色 `rgb(89, 105, 128)`。
- 手机更多指标可展开；原行情创建窗口可打开；电脑更多菜单关闭后原分类管理窗口继续显示；未提交新增、删除或财务动作。
- 组装关闭状态有搜索/主按钮及底部导航；展开后只保留一个业务表单，搜索和导航隐藏，避免与原录入操作栏叠加。
- 单日期利润趋势显示数据不足，同时保留已有精确金额汇总。
- 往来账款另验收空列表及底部搜索；只读页未添加虚构的新建按钮。

使用隔离的本地合成数据和写入阻断；不连接生产数据库。不代表真实账务核对、摄像头、iPhone 软键盘或生产验收。桌面版有用户明确要求的字号/页头变化，不声称像素不变。
