## 防止再次堆积

- `npm run check:unused` 在原 TypeScript 未使用变量检查后增加模块/导出检查；`npm run lint` 同时运行检查器回归测试，因此已有 CI 自动覆盖。
- `npm run audit:unused` 输出结构化报告，不自动删除代码。
- 模块图包含静态导入、重导出、字面量动态导入、require 和 Worker URL；入口区分运行代码、测试和维护脚本，排除编译器隐式加载的 `.d.ts`。
- 导出分析识别别名、namespace、依赖注入 shorthand、动态导入绑定和路由字符串命名导出。未登记的无引用导出使检查失败，必须人工确认。
- `scripts/unused-code-allowlist.json` 仅保留两个具体共享账务状态契约；每项必须有保留理由，不能豁免整个目录。
- 静态分析不等于运行验收：非字面量模块路径、反射和外部消费者仍需人工核对，不能仅凭报告删除公共接口。
