# 型号出入记录手机端：方案 1

用户选定第一张图，2026-10-11 实施；不改桌面、查询接口、金额计算、库存计算或权限。

## 展示与复用

- 手机标题为「出入记录」，商品名称、分类和当前库存只显示一次。
- 使用连续分隔列表，直接显示单据类型、记录的变动方向和数量、单据编号、客户/供应商、制单人、操作时间及原权限允许的单据金额。金额不是现金收付款，也不会根据库存方向改变正负。
- 明细入口仍使用原页面的单据跳转。`组装拆卸`保留为单据类型，不是商品分类。
- 底部搜索由共享 `ErpDetailDrawer` 的 footer 承载；不增加页面私有 fixed 导航或额外 API。
- 使用 `ErpMobileRecordRow`、`ErpDataTable`、`ErpFilterFields`、`ErpDialogShell` 和原有可搜索 `Select`。
- 类型、制单人、日期采用局部草稿筛选：关闭取消，应用才更新查询；重置保留搜索及每页条数。型号变化时重置手机面板状态，原 hook 仍负责查询隔离和分页。
- 默认按后端全量记录的时间倒序。升序沿用原表格当前页排序，并明确标注「仅排序当前页」，不把客户端已加载的一页伪装成全量排序。
- 金额缺失不显示假零；真实 0 显示 ¥0；沿用系统货币格式。长单号及往来方可换行。
- 字体沿用统一 token；输入 16px，最小触控 44px。共享带 footer 的手机 Drawer 采用已有可见视口/键盘变量，避免固定搜索落在键盘后。

## 本地验收

- lint、前后端及服务端测试类型检查、本地完整构建、生产脚本测试、性能预算和依赖审计通过。
- 完整测试 1806 项：1769 通过、37 项条件数据库测试跳过、0 失败；另用一次性本地 PostgreSQL 执行全部 37 项 HTTP 集成测试，37 通过、0 跳过。
- 最终定向测试 32 通过，覆盖完整字段、无金额权限、真实零值、负数、长单号、草稿范围、共享分页默认行为以及桌面隔离。
- 浏览器验证 320×740、390×844、430px 手机、430×480 短视口及 768px 平板、1440×900 桌面。320px 无横向溢出，短视口 footer 可达，输入 16px。
- 390px 验证取消/应用/重置、类型与日期组合、搜索与清除、分页新记录、型号切换无旧记录、当前页升序提示、无金额投影、读取失败及重试恢复、站内浏览器返回先关闭筛选。
- 1440px 前后对比 0 个像素超过 20/255 的变化阈值；仅 JPEG 小幅编码差异，不是布局变化。
- 正常读取控制台 error 为空；错误场景的预期 HTTP 503 单独记录。
- 合成夹具只在 loopback 本地验收服务中启用，所有业务写入拒绝；没有用夹具替代生产真实数据。
- 源图与实际页面全图、首两条记录局部并排对比，经修正往来方前缀、字重、操作色与分页样式后设计验收通过。项目根 `design-qa.md` 为本地完整证据报告，不纳入源码。
