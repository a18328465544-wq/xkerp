# 共享手机列表底部搜索迁移

## 范围与规则

- 用户要求将其他同类搜索框页面一并迁移。在 `codex/mobile-search-scan-20261012` 上继续，以库存方案三为基准；没有改后端、DTO、接口、业务规则或桌面布局。
- `ErpListPage` 的手机底部默认只显示 48px 搜索框，圆角 12px、左右 16px，固定区域含间距/边框为 65px。没有扫码能力时不显示扫码图标或空槽；库存继续通过 `phoneSearchAction` 调用原扫码。
- 原 `phonePrimaryAction / primaryAction` 默认在手机页头以带原名称、禁用状态及原回调的图标入口呈现。新建/登记不再占底部第二行；原权限判断不变。调用方自带的空状态动作仍保留，模板不重复创建同一个动作。
- 组装页「新建组装 / 拆卸」放在页头，仍然展开原 `phoneWorkflow` 表单；真正的提交、开单工作流与核验工作台没有移入搜索框。
- 财务两套共享布局及行情页取消旧的强制底部主按钮配置。`phoneActionPlacement="dock"` 仅保留为专用任务的显式兼容接口，当前这些列表均不再使用。
- 键盘、安全区、浮层隐藏、非活动保活页保护及主滚动区留位继续用既有实现；没有在每个页面重新写样式。
