# 行情参考 API Gap

## 已确认降级

1. 当前没有受登录权限保护的专用行情分页列表接口。V2 读取 `/api/products` 整库快照，并明确在已加载集合内筛选、排序和分页；未伪装服务端分页。
2. `/api/products` 可能仍把原始行情和库存成本字段返回给缺少 `showCost` / `showProfit` 的账号。V2 Adapter 会裁剪字段，但前端隐藏不等于数据安全；未来应在服务端按字段权限脱敏。
3. 创建行情时后端会生成独立的 `SP-MOCK` productId；当前没有商品模板绑定选择契约。V2 保持真实接口行为，不伪造绑定关系。
4. 已上传行情没有独立详情接口。详情抽屉只展示列表快照中的真实字段。

本轮未修改 FastAPI、数据库、API 或权限规则。
